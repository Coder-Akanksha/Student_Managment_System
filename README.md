# 🎓 Student Management System (MERN Stack)

A fully functional, responsive **Full-Stack Web Application** designed to manage student records smoothly. This project features a clean React frontend connected to a secure Node.js/Express backend, with data permanently stored in a MongoDB database.

---

## 🚀 Features
- **Create:** Add new students with Name, Roll Number, and Branch via an interactive form.
- **Read:** Live fetching of student data from MongoDB into a structured frontend table.
- **Delete:** Real-time data deletion from both the UI and the database.
- **Validations:** Unique constraint handling for student Roll Numbers.

---

## 🛠️ Tech Stack Used

| Layer | Technology |
| --- | --- |
| **Frontend** | React.js, Vite, Axios |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB, Mongoose |
| **Testing** | Thunder Client / Postman |
